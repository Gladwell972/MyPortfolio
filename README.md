# GS Sibiya Portfolio

A responsive single-page developer portfolio for GitHub Pages.

## Structure

- `Portfolio/index.html` — page content and navigation sections
- `Portfolio/css/custom.css` — responsive layout, light/dark theme, and styling
- `Portfolio/js/java.js` — theme toggle, mobile navigation, active navigation, contact form actions
- `Portfolio/js/cv.js` — CV preview and download controls
- `Portfolio/documents/CV.pdf` — generated CV PDF

## Publish with GitHub Pages

1. Create a public repository named `Gladwell972.github.io` in your GitHub account.
2. Upload the **contents of the `Portfolio` folder** to the repository root (so `index.html` is at the root).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. After deployment, visit `https://gladwell972.github.io/`.

## Personalise before publishing

- Replace the initials profile placeholder in the hero with your real portrait if desired. For example, add `images/profile.jpg` and update the `.profile-placeholder` markup in `index.html`.
- Verify your email, phone number, social profile URLs, education details and project links.
- Check that the CV information is accurate before sharing it publicly.
- For GitHub Pages, a contact form cannot send email directly from the server because Pages is static hosting. The form opens the visitor's email app or WhatsApp with the message prepared; the visitor must press Send. For automatic form delivery, connect a form service or backend later.
- Update project status labels and add live-demo URLs when projects are deployed.

## Important note about the degree

The portfolio and generated CV use the latest stated major combination: **Computer Science & Business Management**. Confirm this wording matches your official UFS registration before publishing.
